# NASLÉ — Flavoured Mineral Water Landing Page

A responsive, minimalist landing page for NASLÉ, a fictional flavoured mineral water brand.

## Features

- Responsive desktop and mobile design
- Interactive citrus, berry, peach, and yuzu flavours
- Five-bottle promotional offer
- Add-to-bag functionality
- Lost-package reporting button
- Persistent shopping-bag count
- Product and stockist pages
- Stockist form validation
- Keyboard skip link and visible focus styles
- Responsive navigation and sections
- No external image dependencies
